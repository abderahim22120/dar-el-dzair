# دار الجزائر 🍲 — موقع مطعم جزائري

موقع ثابت (HTML/CSS/JS) بدون أي خادم أو قاعدة بيانات: واجهة افتتاحية فخمة، قائمة أطباق، سلة، وطلب بتوصيل للمنزل أو استلام من المحل. يصل الطلب إلى واتساب المحل جاهزاً.

## هيكل المشروع
```
index.html        الصفحة الرئيسية
css/style.css     التصميم
js/data.js        ← هنا تعدّل الأسماء والأسعار والصور ورقم واتساب
js/app.js         منطق الموقع (لا تحتاج لتعديله)
images/           ضع صور الأطباق هنا
```

## أهم خطوة قبل النشر
افتح `js/data.js` وغيّر `wa` إلى رقم واتساب محلك بصيغة دولية بدون `+`، مثال: `213550123456`. وإلا فستصل الطلبات إلى رقم وهمي.

## تعديل المحتوى
كل شيء في `js/data.js`:
- **الاسم والشعار:** `name` و `tag`
- **الأسعار:** حقل `p` في كل طبق
- **أطباق جديدة:** انسخ سطراً من `items` وغيّر `id` إلى رقم غير مكرر
- **الصور:** ضع الصورة في `images/` واكتب `img: "images/اسم-الصورة.jpg"`. يُفضَّل أن تكون أقل من 300KB وبأبعاد مربعة تقريباً
- **رسوم التوصيل:** `fee` و `free`

## التشغيل محلياً
افتح `index.html` في المتصفح مباشرة.

## النشر على GitHub Pages (مجاني)
1. أنشئ مستودعاً جديداً على GitHub وارفع **محتويات** هذا المجلد (يجب أن يكون `index.html` في الجذر).
2. من المستودع: Settings ← Pages.
3. في Source اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط Save.
4. بعد دقيقة أو دقيقتين يظهر رابط الموقع: `https://اسم-المستخدم.github.io/اسم-المستودع/`

لكل تعديل لاحق: عدّل الملف على GitHub واحفظ (Commit) فيتحدّث الموقع تلقائياً.
